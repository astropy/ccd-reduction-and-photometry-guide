# Руководство по обработке CCD данных и звёздной фотометрии с использованием astropy и связанных пакетов

Вдохновением для этой работы послужили два руководства и книга:

+ [A User's Guide to Stellar CCD Photometry with IRAF](https://www.mn.uio.no/astro/english/services/it/help/visualization/iraf/daophot2.pdf) Massey and Davis (1992)
+ [A User's Guide to CCD Reductions with IRAF](http://ircamera.as.arizona.edu/Astr_518/irafguid.pdf) Massey (1997)

# [Последняя опубликованная версия](http://www.astropy.org/ccd-reduction-and-photometry-guide/) руководства

Отрендеренная версия руководства находится [здесь](http://www.astropy.org/ccd-reduction-and-photometry-guide/).
